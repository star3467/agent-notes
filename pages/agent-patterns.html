AI Agent 的四個設計模式

與其把 AI 當成問一句答一句的聊天機器人，不如教它「做事的方法」。這頁先看全貌。

先搞懂：什麼是 AI Agent

教材的定義是 AI Agent = AI Model + Harness：模型負責思考，Harness（外圍的程式、工具、流程與規則）負責讓模型能把事情做完。換句話說，在 LLM 時代，Agent 基本上就是教 AI 用「我們做事的方法」做事情。

重點：聊天機器人是「你問、它答」；Agent 是「你交代目標，它規劃、找資料、反覆嘗試，直到做完」。

四個模式一覽

模式一句話適合的情境
Reflection（反思）先產生初稿，再自我檢查、修改，可重複數次寫作、程式碼、需要品質把關
Tool Use（工具使用）LLM 不擅長的事，呼叫工具來做精確計算、查實際資料、上網搜尋
Planning（規劃）先想一想、打草稿，拆解步驟再執行複雜任務、多步驟流程
Multiagent Collaboration多個 Agent 分工合作任務可拆成不同角色負責

它們可以組合

實務上常常混用：例如一個 PM 角色的 LLM 先做 Planning 拆解任務，分派給會 Tool Use 的 Agent 執行，最後再用 Reflection 檢查結果。
