模式

Multiagent Collaboration：多個 Agent 一起工作

一個 Agent 做不完、做不好的事，讓多個各有專長的 Agent 一起做。

它是什麼

多個 AI Agent 一起工作。每個 Agent 可以有不同角色、提示詞、工具，甚至不同模型。

常見組合

  • PM + 執行者：一個 Agent 拆解並分派，其他 Agent 各自負責查資料、計算、撰寫。
  • 作者 + 評論員：這其實就是 Reflection 的雙角色版本。

Agent 之間怎麼溝通

教材提到 Google 提出的 A2A（Agent-to-Agent），定義了代理之間交換資訊、協作與協調的方式；相對地，MCP 關注的是單一 Agent 如何使用外部工具。

重點：先把單一 Agent 做好（會規劃、會用工具、會反思），再考慮多個 Agent 合作。
備註：本頁內容較精簡，教材對此模式著墨不多；之後可依新資料擴充。
