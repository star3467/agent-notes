概念

RAG（檢索增強生成）

LLM 不知道你腦中的背景。RAG 的做法是讓電腦自動把相關資訊找出來，放進 prompt 再回答。

它是什麼

RAG 的特點：由電腦自動找到相關的資訊，再放進 prompt 讓 LLM 回答。

課程說，RAG 其實也是一種 AI Agent。

使用者問題→取回相關文件→放入 prompt→LLM 回答

怎麼運作

  • 使用者提出問題。
  • 系統取回與問題相關的文件。
  • 把取回的文件放入 prompt。
  • LLM 根據 prompt 回答。

和 Content Engineering 的關係

做好 Content Engineering 需要兩件事：

  • 正確的資訊：LLM 不知道你腦中的背景，要把該給的資料、條件講清楚。
  • 清楚的指引：講明白要它做什麼、輸出成什麼樣子、給誰看。

RAG 對應的是前者：資訊不用手動貼，由電腦自動找來。

備註：課程重點沒有提供檢索的具體做法（例如怎麼找文件）與實際例子，這頁不補充。「RAG 對應正確的資訊」是我的整理，不是教材原文。
重點：RAG ＝ 電腦自動找相關資料 → 放進 prompt → LLM 回答，也算一種 AI Agent。
